# College Student Portal
Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run in VS Code
1. File > Open Folder > select `college-portal`.
2. Install the "Live Server" extension, right-click `index.html`, choose "Open with Live Server".
   (Or just double-click `index.html`; it works from the file system too.)
3. Click Register, create an account, and you are in with demo data.

## Files
- `index.html` – page structure (login/register and app shell)
- `style.css` – minimal styling
- `app.js` – auth, routing, and all eight pages

Data is stored in your browser's localStorage. Passwords are stored in plain text, so this is a learning project: use a real backend with hashed passwords before going live.
